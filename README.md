# URL Shortener Service

A full-stack web application to shorten long URLs, retrieve original links, track usage, and manage short links.

---

## 🚀 Features

- 🔗 Create short URLs from long links
- 📥 Retrieve the original URL using short code
- ✏️ Update an existing short URL
- 🗑️ Delete a short URL
- 📊 Get usage statistics (clicks, timestamps)

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
